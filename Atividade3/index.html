Introdução e conceitos da API

Uma API é um conjunto de regras e protocolos que permite a comunicação entre diferentes aplicativos de software, viabilizando a reutilização de serviços sem precisar programar do zero. Ela atua majoritariamente no back-end, servindo como uma ponte padronizada para o front-end. Essa comunicação ocorre através de um fluxo de Solicitação e Resposta (Request-Response) entre Cliente e Servidor.

Na prática, o cliente (aplicação) escolhe opções em um menu, o garçom (API) leva o pedido até a cozinha (servidor) e entrega o prato (resultado) de volta ao cliente.



Tipos de APIs

  • APIs Abertas (Públicas): Ficam disponíveis para que desenvolvedores externos acessem as funcionalidades livremente pela internet.
  • APIs de Parceiros: São restritas a parceiros comerciais estratégicos, exigindo credenciais de login para o acesso.
  • APIs Internas (Privadas): São mantidas ocultas do público e usadas exclusivamente dentro da própria organização para integrar sistemas internos.
  • APIs Compostas: Permitem acessar e combinar dados de múltiplos serviços em uma única chamada.

Arquitetura REST

  1. Client-Server: Garante a separação entre quem solicita e quem provê o serviço.
  2. Stateless: O servidor não guarda as informações (o estado) do cliente entre as requisições.
  3. Cache: A comunicação com os endpoints ocorre de forma padronizada.
  4. Uniform Interface: Permitem acessar e combinar dados de múltiplos serviços em uma única chamada.
  5. Layered System: O sistema atua em camadas independentes.

Métodos e Códigos HTTP

  • Verbos HTTP: O GET solicita dados. O POST cria ou submete dados. O PUT edita ou substitui informações. O DELETE remove um recurso.
  • Status de Resposta: Os códigos 200 OK e 201 Created indicam sucesso na requisição. Os códigos 400 Bad Request e 404 Not Found indicam erros de sintaxe ou recurso não encontrado. O código 500 indica falha interna no servidor.
